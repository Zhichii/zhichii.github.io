原本是这样子的，2026 年 3 月份我看到 DeepSeek API Docs 用的是 Docusaurus，于是我就打算研究一下 Docusaurus 了，然后我就把我旧的站删了，然后自己不使用 AI 直接研究了一下 Docusaurus，建立起了一个还不错的站

结果到今天我突然发现我的盘有点满了（日常盘满 1/1），所以我就在 DeepSeek Harness 上跟 DeepSeek 说了一下这个，DeepSeek 建议我换 Hugo

我就下载了 Hugo，然后它帮我建了一个站，就这样。
